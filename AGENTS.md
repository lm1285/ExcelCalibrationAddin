# Project Change Rules

- Before fixing a defect or changing behavior, read the relevant sections of
  `Excel校准加载项需求汇总.md` and `Excel校准加载项技术总览.md`.
- Keep implementation and verification consistent with those requirements.
  Update the relevant document when a change clarifies or changes a contract.
- Preserve existing worktree changes. Validate fixes with focused regression
  cases and report any remaining failures or unverified Excel behavior.
